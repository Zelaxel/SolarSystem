# Interactive 3D Solar System (Three.js)

Interactive 3D simulation of the Solar System built with **Three.js**

---

## Main Features

- **Textured Celestial Bodies**
- **Dynamic Camera Control** 
- **Realistic Lighting**

---

## Technologies & Libraries Used

- **[JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)**
- **[Three.js](https://threejs.org/)**
- **[lil-gui](https://lil-gui.georgealways.com/)**
---

## Prerequisites

Make sure you have the following installed on your system:
- [Node.js](https://nodejs.org/) (version 14 or higher).

---

## Installation & Execution

1. **Clone or download** this repository to your local machine.

2. Open a terminal in the root folder of the project (`SolarSystem`) and install dependencies:
   ```bash
   npm install
   
3. Execute and go to your localhost.
   ```bash
   nmp start

## Texture assets

The texture maps and images used for the celestial bodies in this project come from public domain:
- **Sun, Planets, and Moons:** [Solarballs fandom wiki](https://solarballs.fandom.com/wiki/User_blog:Olivernoel/Solarballs_Assets_(For_free_use))
